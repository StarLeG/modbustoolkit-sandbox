# ADR-008: Web UI — серверные страницы + vanilla JS, без сборки

- **Статус:** принято
- **Дата:** 2026-10-29
- **Задача:** TASK-701…752 (Эпик 7); база — ADR-000 (стек), ADR-001 п. 4 (плашка),
  ADR-004 (REST), ADR-005 (WS)

## Контекст

Эпик 7 — web UI для наладчиков: обзор, карта регистров с live-значениями,
редактирование CL/HR, поведения, slave 10, инструменты (конвертеры, генераторы
конфигов, инъекции, журнал), документация. Стек (ADR-000) фронтенд-тулчейн
не содержит: React/Vue добавили бы Node-сборку в деплой (Docker/nginx, Эпик 9)
и вторую экосистему зависимостей. Нужно зафиксировать подход к UI до кода.

## Решения

1. **Без фронтенд-тулчейна**: ни фреймворков, ни сборщика, ни `node_modules`.
   Страницы рендерит сервер (FastAPI, f-строки в `app/api/pages.py`), интерактив
   — vanilla JS (ES-модули) + `fetch` + WebSocket + canvas (графики — без
   библиотек). Правка JS/CSS видна сразу, деплой — только Python.

2. **Многостраничность с общим shell.** Страницы разделов (по ISSUES 7.x):
   `/` — Обзор (7.1), `/registers` — Карта регистров (7.2), `/behaviors` —
   Поведения (7.3), `/timezones` — Часовые пояса, slave 10 (7.4), `/injections` —
   Инъекции ошибок (7.5), `/tools` — Инструменты наладчика (7.5), `/docs` —
   Документация (7.6). Общий shell — навигация, обязательная плашка
   `WARNING_BANNER` (ADR-001 п. 4) на **каждой** странице, подключение статики.
   Каждая страница дальше наполняется своей задачей. Swagger/redoc FastAPI
   живут под `/api/docs`, `/api/redoc`: корневой `/docs` — страница UI.

3. **Статика** — `app/api/static/` (CSS, JS-модули), монтируется `StaticFiles`
   на `/static`. Данные страница не встраивает при рендере, а подтягивает из
   REST (`/api/modbus/*`) и WS (`/ws/state`, `/ws/events`): shell статичен,
   данные живые.

4. **Live-обновления** — те же WS-каналы (ADR-005): `/ws/state` — значения с
   частотой `WS_STATE_HZ`, `/ws/events` — журнал/инъекции/поведения. JS держит
   реконнект с backoff; при потере WS страница остаётся работоспособной
   (REST-фолбэк).

5. **Язык UI — русский** (аудитория — инженеры-наладчики); технические
   обозначения (FC, HEX, float ABCD) — как есть.

## Последствия

- Нет реактивности из коробки: синхронизация WS-кадров с DOM — ручная; для
  десятков элементов на страницу это просто и предсказуемо.
- Плашка и навигация живут в одном месте (shell) — тесты проверяют текст без
  браузера (как TASK-504).
- Сложные виджеты (watch list, live-график, дифф-вью) реализуются точечным JS;
  если UI вырастет за рамки — пересмотр подхода отдельным ADR, а не «тихой»
  миграцией на фреймворк.
- Отсутствие сборки = отсутствие minify/бандла; nginx (Эпик 9) может отдавать
  статику с кэшированием по mtime/версии.
