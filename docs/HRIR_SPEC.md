# Спецификация форматов HR/IR

> Источник: внутренняя спецификация тестового сервера. Нормализовано для репозитория.

## Общее

Тестовый сервер предоставляет данные для **Holding Registers (HR)** и
**Input Registers (IR)** в нескольких форматах, отличающихся типом данных и
порядком байтов/слов. Обозначения: **A — старший байт**, **D — младший байт**
(для 32-битного значения ABCD: A=MSB, D=LSB).

Каждый slave отдаёт данные в своём формате. Регистры нумеруются **с 1**
(1-based, как в спецификации Modbus).

---

## Таблица форматов

| Slave | Формат | Описание | Адреса HR | Адреса IR | Байт на значение |
|---|---|---|---|---|---|
| 1 | `UINT16` | Беззнаковое 16-бит, порядок A B | 1,2,3,…,1024 | 1,2,3,…,1024 | 2 |
| 2 | `UINT32_ABCD` | Беззнаковое 32-бит, A B C D | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 3 | `UINT32_CDAB` | Беззнаковое 32-бит, C D A B | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 4 | `UINT32_BADC` | Беззнаковое 32-бит, B A D C | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 5 | `UINT32_DCBA` | Беззнаковое 32-бит, D C B A | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 6 | `FLOAT_ABCD` | IEEE-754 single, A B C D | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 7 | `FLOAT_CDAB` | IEEE-754 single, C D A B | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 8 | `FLOAT_BADC` | IEEE-754 single, B A D C | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 9 | `FLOAT_DCBA` | IEEE-754 single, D C B A | 1,3,5,…,1023 | 1,3,5,…,1023 | 4 |
| 10 | `UINT16` | Беззнаковое 16-бит, порядок A B | — | 1,2,3,…,268 и 300,301 | 2 (для 268), 4 (для 300,301) |

**32-битные значения** занимают **2 регистра**: значение по адресу `N` читается
из регистров `N` и `N+1`. Адрес следующего значения — `N+2`.

## Slave 10 — метрики времени по часовым поясам

На slave 10 **только IR** (CL/DI/HR отсутствуют, попытки чтения → exception 0x02).

### Блоки по часовым поясам

Для каждой зоны `Z` (0..26) — 8 метрик со смещением 10:

| Смещение | Метрика | Тип |
|---|---|---|
| `1 + 10*Z` | Год | UINT16 |
| `2 + 10*Z` | Месяц (1..12) | UINT16 |
| `3 + 10*Z` | День месяца (1..31) | UINT16 |
| `4 + 10*Z` | Час (0..23) | UINT16 |
| `5 + 10*Z` | Минута (0..59) | UINT16 |
| `6 + 10*Z` | Секунда (0..59) | UINT16 |
| `7 + 10*Z` | День недели (1=Пн..7=Вс) | UINT16 |
| `8 + 10*Z` | Смещение в часах от UTC (со знаком, int16) | INT16 |
| `9 + 10*Z` | *резерв* → 0 | UINT16 |
| `10 + 10*Z` | *резерв* → 0 | UINT16 |

`Z` — индекс зоны:

- `Z = 0..14` → UTC+00:00 … UTC+14:00 (к востоку от Гринвича)
- `Z = 15..26` → UTC−01:00 … UTC−12:00 (к западу, в обратном порядке)

Последняя зона `Z = 26` → адреса 261..270; но блок `1..268` покрывает все
используемые метрики (верхние «дырки» 269, 270 — за пределами карты).

### Примеры расчёта адресов

**Гринвич (UTC+00:00), Z = 0:**

- Год:  `1 + 10*0 = 1`
- Час:  `4 + 10*0 = 4`

**Москва (UTC+03:00), Z = 3:**

- Год:  `1 + 10*3 = 31`
- Час:  `4 + 10*3 = 34`

**UTC−05:00, Z = 19** (15 → −1, 19 → −5):

- Час:  `4 + 10*19 = 194`

### Unix Timestamp

| Адрес IR | Формат | Описание |
|---|---|---|
| 300, 301 | `UINT32_ABCD` | Unix timestamp (секунды с 1970-01-01 UTC), точность ±0.5 с |

## Примеры раскодирования (для тестов)

Вход: 4 байта `0x12 0x34 0x56 0x78` (один регистр = 2 байта):

| Порядок | Байты (A B C D) | uint32 | float (hex) |
|---|---|---|---|
| ABCD | `12 34 56 78` | `0x12345678 = 305419896` | `0x12345678 ≈ 5.6904566139e-28` |
| CDAB | `56 78 12 34` | `0x56781234 = 1450766900` | `0x56781234 ≈ 1.03e13` |
| BADC | `34 12 78 56` | `0x34127856 = 873364566` | `0x34127856 ≈ 1.37e-57` |
| DCBA | `78 56 34 12` | `0x78563412 = 2018915346` | `0x78563412 ≈ 2.44e34` |

> Примечание: значения float — для справки, точные цифры зависят от платформы;
> в тестах используются `struct.pack/unpack` round-trip.

## Соглашения реализации

- Внутреннее представление — **unpacked Python-значения** (`int` для uint16/uint32, `float`
  для FLOAT); кодек конвертирует в регистры при чтении/записи.
- Для `INT16` (смещение UTC) — `struct.pack(">h", value)`.
- Порядок байтов внутри регистра — **big-endian** (Modbus-стандарт, A — старший байт).
- Порядок слов — задаётся форматом (ABCD/CDAB/BADC/DCBA).
- Запись в HR slave N принимает **ровно** значение в формате этого slave.
